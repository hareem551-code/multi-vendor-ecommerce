# 🛒 Multi-Vendor E-Commerce Marketplace

A full-stack Multi-Vendor E-Commerce Marketplace built using the
MERN stack.

The application allows customers to browse products, manage their
shopping cart and place orders. Vendors can manage their products,
while administrators can manage the marketplace.

## 🌐 Live Demo

https://multi-vendor-ecommerce-website-henna.vercel.app/

## 🚀 Features

- User Registration and Login
- Customer Interface
- Vendor/Seller Dashboard
- Admin Dashboard
- Product Management
- Product Search and Filtering
- Shopping Cart
- Order Management
- Responsive Design
- REST API Integration
